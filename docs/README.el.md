# Εγκατάσταση, σύζευξη και ενημέρωση μιας εφαρμογής Ιστού

## Στείλτε έναν πίνακα ελέγχου σε κάποιον που γνωρίζετε

Παράδειγμα. Ο Σεμπάστιαν δημιουργεί μια εφαρμογή Ιστού που δείχνει τις αναχωρήσεις τρένων. Ο θείος του χρησιμοποιεί ήδη την επίσημη εφαρμογή Home Assistant Companion και έχει πρόσβαση στο ταμπλό. Ο Sebastian στέλνει τον σύνδεσμο του προγράμματος περιήγησης μέσω WhatsApp.

1. Στο PWA Web-App Studio, ανοίξτε την εφαρμογή, μεταβείτε στην Access, ενεργοποιήστε τη σύνδεση μέσω της εφαρμογής Companion και αποθηκεύστε. Και οι δύο εφαρμογές πρέπει να φτάσουν στον ίδιο διακομιστή Home Assistant μέσω HTTPS.

2. Ο καλεσμένος σας ανοίγει τον σύνδεσμο WhatsApp στο πρόγραμμα περιήγησής του και επιλέγει Είσοδος μέσω της εφαρμογής Companion. Η εφαρμογή Ιστού εμφανίζει έναν κωδικό συσκευής. Ο επισκέπτης μπορεί να το αντιγράψει αν χρειαστεί.

3. Πατήστε Άνοιγμα Home Assistant. Επιβεβαιώστε ότι η εφαρμογή, ο λογαριασμός και ο κωδικός ταιριάζουν. Εάν η σελίδα σύζευξης ζητά έναν κωδικό, επικολλήστε ή εισαγάγετε τον κωδικό που εμφανίζεται στην εφαρμογή Ιστού. Στη συνέχεια, εγκρίνετε τη σύνδεση.

4. Επιστροφή στην αρχική καρτέλα του προγράμματος περιήγησης. Συνδέεται αυτόματα. Εάν είναι απαραίτητο, πατήστε Έλεγχος έγκρισης. Ο κωδικός ισχύει για πέντε λεπτά και για μία είσοδο.

5. Σε iPhone ή iPad, για να συνδεθείτε στο εγκατεστημένο αντίγραφο, προσθέστε πρώτα τη σελίδα στην Αρχική οθόνη στο Safari. Ανοίξτε το εικονίδιο Αρχικής οθόνης και ξεκινήστε την ίδια διαδικασία έγκρισης εκεί.

## Βρείτε το στούντιο

Χρησιμοποιήστε το εργαλείο ενοποίησης και, στη συνέχεια, ανοίξτε το Studio μέσω του διαλόγου Home Assistant. Εάν εργάζεστε συχνά σε εφαρμογές, ενεργοποιήστε την οντότητα διακόπτη του πλαισίου πλαισίου στις ρυθμίσεις ενοποίησης και ενεργοποιήστε την για να διατηρήσετε τη συντόμευση ορατή.

Για έναν πίνακα ελέγχου συντήρησης, προσθέστε μια κάρτα κουμπιών που πλοηγείται στο /pwa-app-studio. Η προαιρετική οντότητα κουμπιού Open PWA Designer μπορεί επίσης να την ανοίξει στην ενεργή περίοδο λειτουργίας διαχειριστή. Ενεργοποιήστε πρώτα αυτήν την οντότητα. Το Home Assistant το απενεργοποιεί από προεπιλογή.

## Σχεδιάστε και ενημερώστε έναν πίνακα ελέγχου επισκεπτών

Για παράδειγμα, δημιουργήστε έναν πίνακα ελέγχου για επισκέπτες με κάρτα πληροφοριών Wi-Fi και φως βεράντας. Στην περιοχή Περιεχόμενο, επιλέξτε μεμονωμένες κάρτες και επιλέξτε μια προεπιλογή ή εισαγάγετε μια υπάρχουσα κάρτα. Ορίστε τον τίτλο, την οντότητα ή το Markdown χρησιμοποιώντας το οπτικό πρόγραμμα επεξεργασίας και ελέγξτε την προεπισκόπηση του τηλεφώνου.

Στο βήμα της εφαρμογής, ορίστε την έκδοση εφαρμογής σε 1.1 και αποθηκεύστε. Ένας επισκέπτης που έχει ακόμα ανοιχτή την εφαρμογή βλέπει ένα banner ενημέρωσης όταν η εφαρμογή εντοπίσει τη νέα αναθεώρηση. Πατώντας Ενημέρωση εφαρμογής επαναφορτώνεται η προβολή και διατηρείται το εικονίδιο της αρχικής οθόνης και η περίοδος λειτουργίας του προγράμματος περιήγησης. Μια εφαρμογή που ανοίγει αργότερα φορτώνει την τρέχουσα έκδοση όταν συνδεθεί.

## Κοινή χρήση από Android

Χρησιμοποιήστε την κοινή χρήση συνδέσμων στο Studio. Το εγγενές παράθυρο διαλόγου ανοίγει όταν το παρέχει η εφαρμογή ή το πρόγραμμα περιήγησης. Εάν η εφαρμογή Companion δεν προσφέρει κοινόχρηστο API, ανοίξτε τη σελίδα κοινής χρήσης στο πρόγραμμα περιήγησης. Μπορείτε επίσης να αντιγράψετε τον σύνδεσμο.
