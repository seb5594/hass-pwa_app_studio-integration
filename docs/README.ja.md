# Web アプリのインストール、ペアリング、更新

## 知り合いにダッシュボードを送信する

例。セバスチャンは、電車の出発を表示する Web アプリを作成します。彼の叔父はすでに公式 Home Assistant コンパニオン アプリを使用しており、ダッシュボードにアクセスできます。 Sebastian は、WhatsApp 経由でブラウザのリンクを送信します。

1. PWA Web-App Studio で、アプリを開き、「アクセス」に移動し、コンパニオン アプリ経由のサインインを有効にして保存します。どちらのアプリも HTTPS 経由で同じ Home Assistant サーバーに到達する必要があります。

2. ゲストはブラウザで WhatsApp リンクを開き、[コンパニオン アプリ経由でサインイン] を選択します。 Web アプリにはデバイス コードが表示されます。ゲストは必要に応じてそれをコピーできます。

3. 「Home Assistantを開く」をタップします。アプリ、アカウント、コードが一致していることを確認します。ペアリング ページでコードを要求された場合は、Web アプリに表示されているコードを貼り付けるか入力します。次に、サインインを承認します。

4. 元のブラウザタブに戻ります。自動的にサインインします。必要に応じて、「承認の確認」をタップします。コードは 5 分間有効で、1 回のサインインに使用できます。

5. iPhone または iPad で、インストールされたコピーにサインインするには、まず Safari のホーム画面にページを追加します。ホーム画面アイコンを開き、そこで同じ承認プロセスを開始します。

## スタジオを探す

統合ギアを使用し、Home Assistant ダイアログから Studio を開きます。アプリで頻繁に作業する場合は、統合設定でサイドバー パネル スイッチ エンティティを有効にしてオンにし、ショートカットを表示したままにします。

メンテナンス ダッシュボードの場合、/pwa-app-studio に移動するボタン カードを追加します。オプションの「PWA デザイナーを開く」ボタン エンティティをアクティブな管理者セッションで開くこともできます。まずそのエンティティを有効にします。 Home Assistant はデフォルトで無効にします。

## ゲスト ダッシュボードの設計と更新

たとえば、Wi-Fi 情報カードとパティオ ライトを備えた訪問者用のダッシュボードを作成します。 [コンテンツ] で、個々のカードを選択し、プリセットを選択するか、既存のカードをインポートします。ビジュアルエディターを使用してタイトル、エンティティ、または Markdown を設定し、電話プレビューを確認します。

アプリのステップで、アプリのバージョンを 1.1 に設定して保存します。アプリを開いたままのゲストには、アプリが新しいリビジョンを検出すると更新バナーが表示されます。 [アプリの更新] をタップすると、ビューがリロードされ、ホーム画面のアイコンとブラウザ セッションが維持されます。後で開いたアプリは、接続時に現在のバージョンを読み込みます。

## Android から共有

スタジオでリンク共有を使用します。アプリまたはブラウザーが提供すると、ネイティブ ダイアログが開きます。コンパニオン アプリが共有 API を提供していない場合は、ブラウザで共有ページを開きます。リンクをコピーすることもできます。
