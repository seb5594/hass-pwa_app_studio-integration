# 安装、配对和更新网络应用程序

## 将仪表板发送给您认识的人

示例。 Sebastian 创建了一个显示火车出发情况的网络应用程序。他的叔叔已经使用官方 Home Assistant Companion 应用程序，并且可以访问仪表板。 Sebastian 通过 WhatsApp 发送浏览器链接。

1. 在 PWA Web-App Studio 中，打开应用程序，转到“访问”，启用通过配套应用程序登录，然后保存。两个应用程序必须通过 HTTPS 到达同一 Home Assistant 服务器。

2. 您的访客在浏览器中打开 WhatsApp 链接，然后选择通过配套应用程序登录。 Web 应用程序显示设备代码。如果需要，客人可以复制。

3. 点击打开Home Assistant。确认应用程序、帐户和代码匹配。如果配对页面要求输入代码，请粘贴或输入网络应用程序中显示的代码。然后批准登录。

4. 切换回原来的浏览器选项卡。它会自动登录。如有必要，请点击检查批准。该代码的有效期为五分钟，且只能登录一次。

5. 在 iPhone 或 iPad 上，要登录已安装的副本，请首先将该页面添加到 Safari 的主屏幕。打开主屏幕图标并在那里启动相同的审批流程。

## 寻找工作室

使用集成齿轮，然后通过 Home Assistant 对话框打开 Studio。如果您经常使用应用程序，请在集成设置中启用侧边栏面板开关实体并将其打开以保持快捷方式可见。

对于维护仪表板，添加导航到 /pwa-app-studio 的按钮卡。可选的“打开 PWA 设计器”按钮实体也可以在活动管理员会话中打开它。首先启用该实体； Home Assistant 默认禁用它。

## 设计和更新访客仪表板

例如，为访客创建一个带有 Wi-Fi 信息卡和庭院灯的仪表板。在内容下，选择单个卡片并选择预设或导入现有卡片。使用可视化编辑器设置标题、实体或 Markdown 并检查手机预览。

在App步骤中将App版本设置为1.1并保存。当应用程序检测到新版本时，仍打开应用程序的访客会看到更新横幅。点击更新应用程序会重新加载视图并保留主屏幕图标和浏览器会话。稍后打开的应用程序在连接时会加载当前版本。

## 从 Android 分享

在 Studio 中使用链接共享。当应用程序或浏览器提供本机对话框时，本机对话框将打开。如果配套应用程序不提供共享 API，请在浏览器中打开共享页面。您也可以复制链接。
