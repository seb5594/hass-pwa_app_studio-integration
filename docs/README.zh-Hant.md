# 安裝、配對和更新網路應用程式

## 將儀表板傳送給您認識的人

範例。 Sebastian 創建了一個顯示火車出發情況的網路應用程式。他的叔叔已經使用官方 Home Assistant Companion 應用程序，並且可以訪問儀表板。 Sebastian 透過 WhatsApp 發送瀏覽器連結。

1. 在 PWA Web-App Studio 中，打開應用程序，轉到“訪問”，啟用透過配套應用程式登錄，然後儲存。兩個應用程式必須透過 HTTPS 到達同一 Home Assistant 伺服器。

2. 您的訪客在瀏覽器中打開 WhatsApp 鏈接，然後選擇透過配套應用程式登入。 Web 應用程式顯示裝置代碼。如果需要，客人可以複製。

3. 點選開啟Home Assistant。確認應用程式、帳戶和代碼匹配。如果配對頁面要求輸入代碼，請貼上或輸入網路應用程式中顯示的代碼。然後批准登入。

4. 切換回原來的瀏覽器標籤。它會自動登入。如有必要，請點擊檢查批准。此代碼的有效期限為五分鐘，且只能登入一次。

5. 在 iPhone 或 iPad 上，若要登入已安裝的副本，請先將該頁面新增至 Safari 的主畫面。打開主畫面圖示並在那裡啟動相同的審批流程。

## 尋找工作室

使用整合齒輪，然後透過 Home Assistant 對話方塊開啟 Studio。如果您經常使用應用程序，請在整合設定中啟用側邊欄面板開關實體並將其打開以保持快捷方式可見。

對於維護儀表板，新增導航至 /pwa-app-studio 的按鈕卡。可選的「開啟 PWA 設計器」按鈕實體也可以在活動管理員會話中開啟它。首先啟用該實體； Home Assistant 預設為停用它。

## 設計並更新訪客儀表板

例如，為訪客建立一個帶有 Wi-Fi 資訊卡和庭院燈的儀表板。在內容下，選擇單一卡片並選擇預設或匯入現有卡片。使用視覺化編輯器設定標題、實體或 Markdown 並檢查手機預覽。

在App步驟中將App版本設定為1.1並儲存。當應用程式偵測到新版本時，仍開啟應用程式的訪客會看到更新橫幅。點擊更新應用程式會重新載入視圖並保留主畫面圖示和瀏覽器會話。稍後打開的應用程式在連接時會載入當前版本。

## 從 Android 分享

在 Studio 中使用連結共用。當應用程式或瀏覽器提供本機對話方塊時，本機對話方塊將會開啟。如果配套應用程式不提供共享 API，請在瀏覽器中開啟共享頁面。您也可以複製連結。
