# Suiteáil, péireáil agus nuashonraigh aip gréasáin

## Seol deais chuig duine éigin a bhfuil aithne agat air

Sampla. Cruthaíonn Sebastian aip gréasáin a thaispeánann imeacht traenach. Úsáideann a uncail App Companion Home Assistant oifigiúil cheana féin agus tá rochtain aige ar an deais. Seolann Sebastian an nasc brabhsálaí trí WhatsApp.

1. In PWA Web-App Studio, oscail an aip, téigh chuig Access, cumasaigh síniú isteach tríd an Aip Companion, agus sábháil. Caithfidh an dá apps an freastalaí Home Assistant céanna a bhaint amach thar HTTPS.

2. Osclaíonn d’aoi an nasc WhatsApp ina bhrabhsálaí agus roghnaíonn sé Sínigh isteach tríd an Aip Companion. Taispeánann an app gréasáin cód gléas. Is féidir leis an aoi é a chóipeáil más gá.

3. Beartaíonn Oscail Home Assistant. Deimhnigh go meaitseálann an aip, an cuntas agus an cód. Má iarrann an leathanach péireála cód, greamaigh nó cuir isteach an cód a thaispeántar san app gréasáin. Ansin ceadaigh síniú isteach.

4. Téigh ar ais go dtí an bunchluaisín brabhsálaí. Síníonn sé isteach go huathoibríoch. Más gá, tapáil Seiceáil ceadú. Tá an cód bailí ar feadh cúig nóiméad agus le síniú isteach amháin.

5. Ar iPhone nó iPad, chun síniú isteach ar an gcóip suiteáilte, cuir an leathanach leis an Scáileán Baile in Safari ar dtús. Oscail an deilbhín Scáileán Baile agus cuir tús leis an bpróiseas ceadaithe céanna ansin.

## Faigh an Stiúideo

Bain úsáid as an bhfearas comhtháthú, ansin oscail an Stiúideo tríd an dialóg Home Assistant. Má oibríonn tú ar aipeanna go minic, cumasaigh an t-aonán lasc Painéal Taoibh sna socruithe comhtháthaithe agus cuir ar siúl é chun an aicearra a choinneáil le feiceáil.

Le haghaidh painéal cothabhála, cuir cnaipe-chárta leis a théann chuig /pwa-app-studio. Is féidir leis an eintiteas cnaipe Dearthóir PWA roghnach a oscailt freisin i do sheisiún riarthóra gníomhach. Cumasaigh an t-aonán sin ar dtús; Déanann Home Assistant é a dhíchumasú de réir réamhshocraithe.

## Dear agus nuashonraigh painéal aoi

Mar shampla, cruthaigh painéal do chuairteoirí le cárta faisnéise Wi-Fi agus solas patio. Faoi Ábhar, roghnaigh cártaí aonair agus roghnaigh réamhshocrú nó iompórtáil cárta atá ann cheana féin. Socraigh an teideal, an t-eintiteas nó Markdown ag baint úsáide as an eagarthóir amhairc agus seiceáil an réamhamharc teileafóin.

Sa chéim App socraigh an leagan App go 1.1 agus sábháil. Feiceann aoi a bhfuil an aip oscailte fós aige bratach nuashonraithe nuair a bhraitheann an aip an t-athbhreithniú nua. Athlódálann an aip Tapping Update an radharc agus coinníonn sé deilbhín an scáileáin baile agus seisiún an bhrabhsálaí. Lódálann aip a osclaíodh níos déanaí an leagan reatha nuair a bhíonn sé ceangailte.

## Roinn ó Android

Úsáid Link sharing sa Stiúideo. Osclaíonn an dialóg dúchais nuair a sholáthraíonn an aip nó an brabhsálaí é. Mura dtairgeann an App Companion API scaireanna, oscail an leathanach scaireanna sa bhrabhsálaí. Is féidir leat an nasc a chóipeáil freisin.
