# Installa, koppja u aġġorna web app

## Ibgħat dashboard lil xi ħadd li taf

Eżempju. Sebastian joħloq app tal-web li turi t-tluq tal-ferroviji. Zijuh diġà juża l-App Companion uffiċjali Home Assistant u għandu aċċess għad-dashboard. Sebastian jibgħat il-link tal-browser permezz ta 'WhatsApp.

1. F'PWA Web-App Studio, iftaħ l-app, mur Aċċess, ippermetti d-dħul permezz tal-App Companion, u ssalva. Iż-żewġ apps għandhom jilħqu l-istess server Home Assistant fuq HTTPS.

2. Il-mistieden tiegħek jiftaħ il-link WhatsApp fil-browser tagħhom u jagħżel Idħol permezz tal-App Companion. L-app tal-web turi kodiċi tal-apparat. Il-mistieden jista’ jikkopjaha jekk ikun meħtieġ.

3. Tektek Iftaħ Home Assistant. Ikkonferma li l-app, il-kont u l-kodiċi jaqblu. Jekk il-paġna tat-tqabbil titlob kodiċi, waħħal jew daħħal il-kodiċi muri fl-app tal-web. Imbagħad approva s-sign-in.

4. Aqleb lura għat-tab oriġinali tal-browser. Huwa jiffirma awtomatikament. Jekk meħtieġ, tektek Iċċekkja l-approvazzjoni. Il-kodiċi huwa validu għal ħames minuti u għal dħul wieħed.

5. Fuq iPhone jew iPad, biex tidħol fil-kopja installata, l-ewwel żid il-paġna mal-Iskrin Home f'Safari. Iftaħ l-ikona tal-Iskrin Home u ibda l-istess proċess ta' approvazzjoni hemmhekk.

## Sib l-Istudjo

Uża l-irkaptu ta 'integrazzjoni, imbagħad iftaħ l-Istudjo permezz tad-djalogu Home Assistant. Jekk taħdem fuq apps ta 'spiss, ppermetti l-entità tal-iswiċċ tal-Panel tal-Istrixxa tal-ġenb fis-settings tal-integrazzjoni u ixgħelha biex iżżomm is-shortcut viżibbli.

Għal dashboard tal-manutenzjoni, żid karta tal-buttuna li tinnaviga lejn /pwa-app-studio. L-entità fakultattiva tal-buttuna Open PWA Designer tista 'wkoll tiftaħha fis-sessjoni tal-amministratur attiv tiegħek. Jippermettu dik l-entità l-ewwel; Home Assistant jiskonnettjaha awtomatikament.

## Iddisinja u aġġorna dashboard tal-mistieden

Per eżempju, oħloq dashboard għall-viżitaturi b'karta ta' informazzjoni Wi-Fi u dawl tal-patio. Taħt Kontenut, agħżel karti individwali u agħżel issettjat minn qabel jew importa karta eżistenti. Issettja t-titlu, l-entità jew Markdown billi tuża l-editur viżwali u ċċekkja l-previżjoni tat-telefon.

Fil-pass tal-App issettja l-verżjoni tal-App għal 1.1 u ssejvja. Mistieden li għad għandu l-app miftuħa jara banner ta’ aġġornament meta l-app tiskopri r-reviżjoni l-ġdida. Meta ttektek l-app Aġġornament terġa' tgħabbi l-veduta u żżomm l-ikona tal-iskrin tad-dar u s-sessjoni tal-brawżer. App miftuħa aktar tard jgħabbi l-verżjoni attwali meta konnessa.
