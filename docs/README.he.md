# התקן, התאמה ועדכן אפליקציית אינטרנט

## שלח לוח מחוונים למישהו שאתה מכיר

דוגמה. סבסטיאן יוצר אפליקציית אינטרנט המציגה את יציאות הרכבת. דודו כבר משתמש באפליקציה הרשמית Home Assistant Companion ויש לו גישה ללוח המחוונים. סבסטיאן שולח את הקישור לדפדפן דרך WhatsApp.

1. ב-PWA Web-App Studio, פתח את האפליקציה, עבור אל Access, הפעל כניסה דרך אפליקציית Companion ושמור. שתי האפליקציות חייבות להגיע לאותו שרת Home Assistant באמצעות HTTPS.

2. האורח שלך פותח את הקישור WhatsApp בדפדפן שלו ובוחר היכנס דרך אפליקציית Companion. אפליקציית האינטרנט מציגה קוד מכשיר. האורח יכול להעתיק אותו במידת הצורך.

3. הקש על פתח את Home Assistant. אשר שהאפליקציה, החשבון והקוד תואמים. אם דף ההתאמה מבקש קוד, הדבק או הזן את הקוד המוצג באפליקציית האינטרנט. לאחר מכן אשר את הכניסה.

4. עבור חזרה לכרטיסיית הדפדפן המקורית. זה נכנס אוטומטית. במידת הצורך, הקש על בדוק אישור. הקוד תקף לחמש דקות ולכניסה אחת.

5. באייפון או אייפד, כדי להיכנס לעותק המותקן, הוסף תחילה את הדף למסך הבית בספארי. פתח את סמל מסך הבית והתחל את אותו תהליך אישור שם.

## מצא את הסטודיו

השתמש בציוד האינטגרציה ולאחר מכן פתח את הסטודיו דרך תיבת הדו-שיח Home Assistant. אם אתה עובד על אפליקציות לעתים קרובות, הפעל את ישות המתג של לוח סרגל הצד בהגדרות האינטגרציה והפעל אותה כדי לשמור על קיצור הדרך גלוי.

עבור לוח מחוונים לתחזוקה, הוסף כרטיס לחצן שמנווט אל /pwa-app-studio. הישות האופציונלית של הלחצן Open PWA Designer יכולה גם לפתוח אותה בהפעלת המנהל הפעילה שלך. הפעל תחילה את הישות הזו; Home Assistant משבית אותו כברירת מחדל.

## עיצוב ועדכן לוח מחוונים לאורח

לדוגמה, צור לוח מחוונים למבקרים עם כרטיס מידע Wi-Fi ותאורת מרפסת. תחת תוכן, בחר כרטיסים בודדים ובחר הגדרה מראש או ייבא כרטיס קיים. הגדר את הכותרת, הישות או Markdown באמצעות העורך החזותי ובדוק את התצוגה המקדימה של הטלפון.

בשלב האפליקציה הגדר את גרסת האפליקציה ל-1.1 ושמור. אורח שהאפליקציה עדיין פתוחה רואה באנר עדכון כאשר האפליקציה מזהה את הגרסה החדשה. הקשה על אפליקציית עדכון טוענת מחדש את התצוגה ושומרת על סמל מסך הבית והפעלת הדפדפן. אפליקציה שנפתחה מאוחר יותר טוענת את הגרסה הנוכחית כשהיא מחוברת.

## שתף מאנדרואיד

השתמש בשיתוף קישורים בסטודיו. תיבת הדו-שיח המקורית נפתחת כאשר האפליקציה או הדפדפן מספקים אותה. אם אפליקציית Companion לא מציעה API לשיתוף, פתח את דף השיתוף בדפדפן. ניתן גם להעתיק את הקישור.
